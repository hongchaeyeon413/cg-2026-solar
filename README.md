### 검증

1. gl.clearColor(1.0, 0.5, 0.0, 1.0)은 무슨 색상?

    -예측: Red 100%, Green 50%, Blue 0%, Alpha 100%이므로 선명한 주황색(Orange)일 것이다.

    -결과: 캔버스 바탕화면이 주황색으로 채워진다.

    -왜: Red 빛에 Green 빛을 절반 섞여 주황색이 되며, Alpha 1.0은 완전 불투명을 의미한다.


2. resize() 호출 제거 후 창 크기 변경 시 영향

    -예측: 창 크기를 조절하면 화면이 찌그러지거나 깨질 것이다.

    -결과: 육안으로는 배경색이 단색이라 차이가 거의 안 보였지만, 개발자 도구(F12) 콘솔에서 document.getElementById('glcanvas').width 를 입력해 확인한 결과, canvas.width 값이 브라우저 기본값인 300으로 고정되어 있는 것을 확인함 (정상 상태에서는 실제 창 크기 × devicePixelRatio에 맞는 훨씬 큰 값이 나옴)

    -왜: resize()가 draw() 안에서 매 프레임 호출되며 canvas.width/height와 gl.viewport를 갱신해주는데, 이 호출을 지우면 캔버스의 실제 렌더링 해상도가 한 번도 설정되지 않아 브라우저 기본값(300×150)에 그대로 고정됨. CSS(width:100vw 등)는 화면에 보이는 크기를 계속 화면에 맞게 늘려주지만, 그 안에 그려지는 내용물의 실제 해상도는 바뀌지 않기 때문. 지금은 배경이 단색이라 눈으로는 티가 안 나지만, 원이나 도형을 그리기 시작하면 해상도 차이가 흐릿함/계단현상으로 드러날 것으로 예상됨.


3. 'webgl2' 를 'webgl' 로 바꾸면 이 코드는 여전히 동작하나요? 콘솔에 무엇이 나오나요?

    -예측: 화면이 안 나올 것 같다.

    -결과: 코드에서 다음과 같이 변경하여 실행했다.

    ```js
    const gl = canvas.getContext('webgl');
    console.log('WebGL2 준비 완료:', gl.getParameter(gl.VERSION));
    ```

    그 결과 콘솔에 "WebGL2 준비 완료: WebGL 1.0 (OpenGL ES 2.0 Chromium)"이라는 메시지가 출력되었으며 에러는 발생하지 않았다.

    -왜: 지금 코드는 배경색을 칠하기만 하는 극도로 단순한 작업이라서 WebGL 1.0의 기능만으로도 충분하기 때문이다.
